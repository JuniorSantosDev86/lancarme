# QA Block Checklist

Antes de aprovar qualquer bloco:

- [ ] Escopo conferido contra spec.
- [ ] Plan respeitado.
- [ ] Tasks concluídas.
- [ ] Testes backend passam.
- [ ] Testes frontend passam.
- [ ] Build frontend passa.
- [ ] Docker Compose validado quando aplicável.
- [ ] UI PT-BR.
- [ ] Responsivo quando houver UI.
- [ ] Estados loading/error/empty tratados.
- [ ] Workspace isolation quando houver dados multi-tenant.
- [ ] Créditos de IA quando houver IA.
- [ ] Audit log quando houver ação crítica.
- [ ] Segurança revisada.
- [ ] LGPD revisada.
- [ ] Documentação atualizada.
- [ ] Relatório final gerado.
