# LGPD Checklist

- [ ] Mapear dados pessoais coletados.
- [ ] Definir finalidade por tipo de dado.
- [ ] Minimizar campos obrigatórios.
- [ ] Criar política de privacidade.
- [ ] Criar termos de uso.
- [ ] Explicar uso de IA.
- [ ] Permitir exclusão de conta.
- [ ] Planejar exportação de dados.
- [ ] Definir retenção.
- [ ] Controlar autorização de provas sociais.
- [ ] Não usar dados de workspace em exemplos globais.
- [ ] Registrar consentimentos importantes.
- [ ] Documentar fornecedores: IA, e-mail, storage, pagamentos, analytics.
- [ ] Criar runbook de incidente.
