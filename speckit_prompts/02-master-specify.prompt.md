# Prompt para `/speckit.specify` — Master Product Spec

```txt
Especifique o produto Lançar.me como uma plataforma SaaS robusta para lançamentos digitais com IA.

O Lançar.me deve ser uma sala de guerra para infoprodutores, mentores, experts, agências, coprodutores e gestores de tráfego estruturarem oferta, criarem campanha, gerarem conteúdo, copy, criativos, plano de tráfego, funil, calendário, acompanhamento de entrega, provas sociais e relatórios pós-lançamento.

Módulos obrigatórios do produto final:
1. Command Center;
2. Strategy Core;
3. Launch Strategy Room;
4. ConteúdoMatriz;
5. Copy Room;
6. Creative Room;
7. Traffic Room;
8. Funnel Map;
9. Calendar & Execution;
10. MentorFlow;
11. Proof Vault;
12. Analytics & AI Diagnosis;
13. AI Agents;
14. Billing & AI Credits;
15. File Storage;
16. Audit Logs;
17. Security & LGPD;
18. Settings & Integrations.

Requisitos não funcionais obrigatórios:
- frontend React/TypeScript;
- backend Java/Spring Boot;
- PostgreSQL;
- multi-tenancy com workspace isolation;
- autenticação e autorização rígidas;
- LGPD by design;
- IA com créditos e logs;
- pagamentos e webhooks idempotentes;
- upload privado;
- testes unitários, integração e E2E;
- documentação viva;
- deploy em VPS com Docker;
- código limpo de padrão profissional.

O produto não deve prometer faturamento garantido, ROAS garantido, aprovação de anúncios ou substituição total de estratégia humana.

Crie a specification macro com user stories, requisitos funcionais, critérios de aceite, entidades principais, fluxos críticos, riscos e métricas de sucesso. Não implemente código ainda.
```
