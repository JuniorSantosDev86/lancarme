# Prompt para `/speckit.constitution`

Use este conteúdo ao rodar o comando de constitution no Codex/Claude Code.

```txt
Crie ou atualize a constitution do projeto Lançar.me.

O Lançar.me é uma plataforma SaaS robusta para infoprodutores, mentores, experts, agências, coprodutores e gestores de tráfego planejarem, criarem, executarem, acompanharem e analisarem lançamentos digitais com IA.

A arquitetura oficial deve ser:
- frontend React + TypeScript + Vite;
- backend Java 21 + Spring Boot 3;
- PostgreSQL;
- Flyway;
- Spring Security;
- Docker Compose;
- VPS Hostinger no início;
- Cloudflare/R2;
- AI Gateway no backend Java;
- Python apenas como worker auxiliar futuro, nunca como backend principal.

A constitution deve estabelecer como leis permanentes:
1. segurança antes de velocidade;
2. LGPD desde a fundação;
3. multi-tenancy por workspace;
4. validação server-side obrigatória;
5. IA por créditos, nunca ilimitada;
6. prompts versionados;
7. logs de IA e billing;
8. arquivos privados por padrão;
9. testes automatizados por bloco;
10. código limpo com padrão de empresa grande;
11. controllers Spring sem regra de negócio;
12. React sem regra crítica de domínio;
13. DTOs separados de entidades;
14. webhooks idempotentes;
15. backup e restore obrigatórios para produção;
16. documentação viva;
17. execução em blocos pequenos;
18. UI em PT-BR;
19. proibição de promessas de faturamento/ROAS garantido;
20. preservação de arquitetura modular.

A constitution deve ser objetiva, forte, verificável e útil para orientar /speckit.specify, /speckit.plan, /speckit.tasks e /speckit.implement.
```
